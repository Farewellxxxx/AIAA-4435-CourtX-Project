# CourtX 反应式战术练习

运行 `Windows_Reactive/CourtX Reactive.exe`。原来的 `Windows` 自由练习和 `Windows_Tactics` 稳定战术版仍保留。

## 开始

1. 选择高位挡拆或高位接应／传切，再选择 01 持球开局或 04 无球开局。角色不会随球权切换。
2. 挡拆可选 Drop 沉退、Switch 换防、Blitz 夹击或随机变式。高位传切采用盯防、协防与回位。
3. 掩护站定后，持球人绕过掩护，防守再作反应。04 可短顺下或顺下，05 根据协防拉开或空切。光圈提供建议，不限制自由移动。

## 操作

| 按键 | 动作 |
|---|---|
| WASD / 鼠标 | 移动 / 转头 |
| Shift | 按住跑步，放开恢复步行 |
| Tab | 按住实时俯视，放开回到第一人称；球和球员继续运动 |
| 1 / 2 | 选择另一名队友 |
| Q | 按住准备传球，松开出球；按住越久球速越高 |
| E | 无球时向当前持球人要球，3.5 秒内有效；被挡住时队友会等待、换角度，受压时也可能传给其他安全队友 |
| V | 结束当前片段并打开本地复盘 |
| R | 重开相同种子的场景 |
| Esc / F1 | 菜单暂停 / 显示或收起操作提示 |

成功判断包括实际接到顺下球、掩护后给有空间的弱侧队友，以及传切中的第三人中转。它们是原型内的练习目标，并不表示篮球只有一个正确答案。强行传球、接球时反向跑开，都可能真实失误。

## 复盘

- 左侧是实际记录的位置和自己的轨迹，灰线为当时的盯防关系，亮线为选中出手的实际传球目标。
- 拖动时间条或点击上一／下一出手查看关键帧。右侧默认评估你最后一次传球；本回合没有你出球时，会明确写出是哪位队友的选择。
- “出手时线路较清楚”和“实际接稳了”是两件事。预测用当前防守位置、速度与真实碰撞体估算，不能保证结果。
- “同一场景再练”保留种子与防守选择；“下一场景”更换种子，随机模式会重新抽取变式。相同种子仍允许你做不同选择。
- 每次复盘或重开会把已进行的片段保存为程序旁 `Replays` 文件夹中的 JSON 和中文 TXT。保存失败会在复盘界面显示。

当前默认全部在本地运行，没有接入 LLM。可选扩展只接收结构化事实和已有规则评语，不能改变实时球员决策。此版本没有投篮、计分、抢篮板或完整比赛；复盘只讨论跑位、传球窗口和接球执行。没有宣称规则评分经过教练或学习效果验证。

## 稳定版与协作接口

稳定版标签：`v0.3-tactics-stable-20261109`，源码基线 `dc4b774`。备份位于 `Preview/Backups/Stable-20261109`。新开发分支：`feature/reactive-tactics-review`。

`TacticalBall` 仍是唯一球权管理者；`TacticalSession` 保留传球、接球、阶段事件；`ReactiveTactics` 只生成站位意图和盯防分配。队友可替换角色模型与 Animator，通过 `TacticalActor.Action` 映射动画，无需改球权逻辑。

第三方移植与许可见 `docs/reactive-sources.md` 和 `ThirdPartyNotices/BasketWorld-MIT.txt`。
