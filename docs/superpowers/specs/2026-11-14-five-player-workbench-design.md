# CourtX 五人制战术板与即时回放

用户在 2026-11-14 明确批准按本轮对话设计实施并交付可直接运行的 Windows 版本；常规实施、测试与修整无需重复确认。

## 已确认设计
- 两个主入口：战术板、即时回放。取消读防守挑战、独立 What-if 页及自动答题暂停。
- 两个入口共用同一 2D 核心：球场、播放/倍速/节点/时间轴、悬停任务、短拖尾、掩护标志、暂停拖动及规则续演。
- 完整 5v5 对 2–3 联防，进攻预设为中锋提中、后卫挡拆发起、牛角射手（暂按一套）。选进攻角色和开局持球者，防守选择总体策略。
- 参考 CourtLab 网页的浅底、深绿球场、侧栏卡片与排版。中央球场突出；右侧仅当前攻防意图。个人任务移到球员悬停。
- 轨迹只保留最近 2–3 秒，旧段收细淡出；暂停按回放时钟冻结；拖动编辑不伪造运动轨迹。
- 任意暂停时刻（含传球中）可拖动任一攻防球员；保留完整局面状态，规则从新局面继续。原演练/真实回放不可被编辑覆盖。能撤销和恢复原片段。假设分支明确标识。
- 正常 3D 练习改为 5v5，五个进攻角色可选；继续走跑/Shift。鼠标朝向选队友，Q 单次传球，E 要球，无蓄力、力度、球速操作。明显目标反馈、合理接球辅助。模型保留，补正面眼睛。持续防守、失败后可再 call/重练。
- 3D 以站位和决策为目标，成功不依赖精确接球动作。3D 实际经过可回到即时回放。2D What-if 不带入 3D；开始玩始终从战术预设开局。

## 方案与架构
沿用现有 Unity/C#/IMGUI 和场地模型。复用既有 3v3 控制器会把人数、旧记录和评分的硬编码混在一起；另做网站会割裂正常 3D 与回放。因此新增独立的五人制状态/规则核心及记录格式，2D 教学、假设分支和 3D 共用其数据与规则，旧类与旧场景保持可构建。

参考 HTML 是一盯四联教学模型，只参考规则分层思路，重新实现 2–3 联防职责。规则教学推演不作实战命中率预测。

## 实施决定
- 2D 拖动默认改变当前站位，继续后恢复规则行动；可固定球员以维持假设。
- 防守策略：均衡轮转、收缩护筐、外线施压；联防上二下三职责保留。
- 新记录保存至 Replays5v5，包含位置、速度、球权、空中球、阶段、意图与事件。原 3v3 文件不转换或覆盖。
- 一个新 Unity 场景复用原球场与人物几何。新程序单独输出 Windows_FivePlayer；旧构建及用户记录保持原样。
- 所有安装、Unity 缓存和交付大文件放 E:；托管 worktree 的源码在 C:。

## 验收
三套进攻 × 三种防守可演示；十人规则稳定；角色选择正确；两个入口任意时间编辑分支不污染原记录；空中球分叉能继续；暂停/时间轴/撤销无跳变；单次 Q 出球、E 请求及重复 call 正常；实际一轮可保存、重启加载和再次推演。检验 1024×576、1280×720、1920×1080 窗口，原核心回归通过，新规则与集成测试通过，真实可运行程序做鼠标键盘检查，最终独立审核。
