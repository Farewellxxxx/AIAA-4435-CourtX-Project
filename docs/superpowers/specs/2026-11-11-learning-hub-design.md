# CourtX 战术学习与复盘中心

用户已确认执行本设计，并明确要求作为 CourtX 自有功能呈现。产品界面、操作说明与新文档不使用“借鉴朋友”等表述。

## 目标与范围
在一个离线 Unity 程序中连接战术演练、What-if 对比、六道读防守挑战、第一人称练习和实际复盘。保留 3v3、两套现有配合、01/04 可控角色、六人站位、防守反应、真实球权及现有操作。继续使用本地规则，保留 LLM 与动画替换接口。

## 已选方案
沿用 Unity/C#/IMGUI，新建页面式学习中心。相比另建网页再传文件，同一程序可直接传递场景配置与结束回合。相比嵌入浏览器，无需新增运行依赖。现有源码检出路径保留，开发新分支，独立输出 Windows_Learning；旧源码打标签/归档，旧程序不覆盖。

## 内容与交互
- 战术演练：内置八种已记录的真实 3v3 示例（两角色×三种挡拆防守，外加两角色传切）。明确显示“教学示例 / 记录回放”，按实际阶段、出手与结果生成节点，播放、暂停、慢放、定位，给出各人任务及适用条件。
- What-if：从相同开局、角色、种子开始实际练习，可改变防守或人的操作。固定基准回合 A，记录比较回合 B，检查初始位置与配置是否可比。共享时间轴切换 A/B，展示各自出手风险和实际结果。不将操作不同的两次练习当作单一因果实验，不声称能精确续演任意历史时刻。
- 读防守挑战：至少六题，分别覆盖掩护时机、换防、夹击、无球高位接应、传后空切和传球窗口。题目绑定内置记录中的实际时刻/出手；有三个选项、针对性反馈、成立条件、返回演练和从开局练习。模块内切换保留回答，可主动重答。
- 实战复盘：保留现有复盘能力，显示真实结束回合，历史列表可读取程序自己的 Replays 文件。可重练该场景、作为对比基准、返回教学。未记录视线或注意力，不推断玩家“已经看见/忽略”某个防守人；只描述行为及发生的事件。
- 统一布局：中文导航、左侧设置/记录，中间完整球场，右侧任务/题目/解释，底部进入练习及相关操作。保持小窗口下可读，长内容可滚动。

## 数据与边界
共享场景配置（战术、角色、防守、种子）与原有 TacticalEpisode。扩展记录元数据时保持旧 JSON 可读；未知/损坏/过大历史文件跳过并说明。教学示例与用户练习记录分开标识。无新比赛人数、投篮/计分/篮板、多人联机或 VR 功能。

## 验收
两套战术都能走完演练→练习→实际复盘→重练；六题可回答并解释；What-if 比较实际记录且校验相同开局；原核心测试继续通过；三轮迭代留记录；真实窗口检查并保存录像/截图。独立审核后交付新 EXE、ZIP、中文说明和验证证据，推送新分支，关闭测试实例，保持电脑开机。
