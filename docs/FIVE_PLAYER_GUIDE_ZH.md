# CourtX 5v5 使用说明

## 启动
打开 `Windows_FivePlayer_1116/CourtX.exe`（11 月 16 日暂停布防版）。移动或分享时保留整个文件夹，不要只复制 EXE。单机离线运行，无需 Unity 编辑器。

## 两个入口
- **战术板**：选择中锋提中、后卫挡拆发起或牛角射手战术，再选代入角色、开局持球人和整体防守策略。
- **即时回放**：查看每一轮正常 3D 练习的实际经过。新记录保存在程序旁 `Replays5v5`。

角色是你代入的进攻球员，球权转移不会改变这个身份。五名进攻编号 01–05，五名防守编号 X1–X5。当前版本的防守基础是 2–3 联防，三种策略分别偏向均衡轮转、收缩护筐、外线施压。

## 共用的战术板操作
播放/暂停、倍速、时间轴和前后节点均在球场下方。悬停任一球员，短暂停留后显示他此刻的任务。右侧只显示当前攻防意图。

球员只留下最近 2.5 秒的轨迹；越旧越淡、越细。暂停时轨迹冻结，拖动摆位不会被当成运动路线。球在空中时显示简短的传球参考线；掩护形成时显示掩护标志。

## 暂停帧内布防
1. 在演练或某轮真实回放的任意时刻暂停。
2. 拖动任一进攻或防守球员，可连续调整多人。
3. 拖动时，其他防守人立即重新分配职责和位置；时间、战术阶段不前进，其他进攻球员不自动跑位。
4. 点击“撤销”恢复上一次摆位及其补防结果；“返回原片段”清除假设，回到原来的这一帧。

场上会明确标出“暂停布防”。你拖动的人自动固定在新位置；拖动多人时，之前摆好的人也保持不动。防守按持球压迫、护筐、邻近接应点等职责分配，优先保护球侧和篮下。固定过多人可能留下弱侧空缺，界面会提示。悬停防守人可以查看他调整后的职责。

原教学演练和真实回放不被改写。成功、失误或传球飞行中的帧也可以摆位，原阶段和空中球进度保留；它不会偷偷重新开始一轮。选中进攻球员后仍可手动“设为持球者”，这是你明确改变球权的假设。

暂停布防时，“播放原片段”或“原片单步”会清除当前临时摆位并播放原记录；时间轴和前后节点也回到原记录。这里先用于一帧内的站位推敲，不模拟摆位后的未来运动。布防是可解释的教学规则，不是实战概率预测。

## 选择历史练习

左侧保留多轮实际练习，每条卡片都能点击。绿色卡片和球场右上角的轮次显示当前选择，底部显示日期及准确时长。条目超过视口可滚轮滚动；点选列表后也可用上下方向键切换。离开再返回即时回放时，继续打开上次选中的回合。新记录的时间精确到秒。

本机新版已复制旧版的历史回合，旧文件保持原样；新练习保存到新版目录里的 Replays5v5。分享 ZIP 不包含个人练习记录，需要时可自行连同 Replays5v5 文件夹一起复制。

## 正常 3D 练习
点击“开始 3D 练习”，从当前选择的战术预设开局。2D 的任意编辑分支不会带入 3D。

| 操作 | 按键 |
|---|---|
| 移动 / 加速 | WASD / 按住 Shift |
| 看向队友 | 鼠标；点击画面锁定鼠标 |
| 选择传球对象 | 指向队友出现目标提示；也可用 1–5 选择对应编号 |
| 直接传球 | 持球时按一下 Q，无需蓄力 |
| 要球 | 无球时按 E，队友会根据传球条件回应 |
| 实时俯视 | 按住 Tab，松开回第一人称 |
| 再 call 当前战术 | C，在当前局面重新组织；丢球后恢复进攻方持球 |
| 从预设重开 | R，已有练习片段会归档 |
| 结束并看回放 | V |
| 暂停回战术板 | Esc，可点击“继续暂停的练习”返回 |

传球速度、力度和接球辅助由系统处理。传球仍受实际线路影响，明显被防守封住的线路可能丢球；成功目标着重于站位和战术选择。角色头部有正面眼睛，朝向与当前行动一致。

单轮练习最长 5 分钟，届时自动结束并打开回放。失误或成功后都能按 C 再组织，也能按 V 查看这一轮。

## 记录与旧版本
程序会保留最近的实际练习列表，重新启动可继续读取。保存失败时会明确提示并提供重试。未知或损坏记录会跳过并说明数量。

旧的 Windows_Learning、Windows_LearningPolish、Windows_Readability 等程序及其 Replays 文件保持原样。五人制使用新记录格式，旧 3v3 回放继续在旧程序中查看。

本版包含正常第一人称桌面练习；未接入头显控制器或 3D What-if，也没有完整比赛计分、篮板与犯规裁判。
