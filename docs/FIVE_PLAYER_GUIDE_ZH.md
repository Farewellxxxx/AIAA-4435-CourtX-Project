# CourtX 5v5 使用说明

## 启动
打开 `Windows_FivePlayer/CourtX.exe`。移动或分享时保留整个文件夹，不要只复制 EXE。单机离线运行，无需 Unity 编辑器。

## 两个入口
- **战术板**：选择中锋提中、后卫挡拆发起或牛角射手战术，再选代入角色、开局持球人和整体防守策略。
- **即时回放**：查看每一轮正常 3D 练习的实际经过。新记录保存在程序旁 `Replays5v5`。

角色是你代入的进攻球员，球权转移不会改变这个身份。五名进攻编号 01–05，五名防守编号 X1–X5。当前版本的防守基础是 2–3 联防，三种策略分别偏向均衡轮转、收缩护筐、外线施压。

## 共用的战术板操作
播放/暂停、倍速、时间轴和前后节点均在球场下方。悬停任一球员，短暂停留后显示他此刻的任务。右侧只显示当前攻防意图。

球员只留下最近 2.5 秒的轨迹；越旧越淡、越细。暂停时轨迹冻结，拖动摆位不会被当成运动路线。球在空中时显示简短的传球参考线；掩护形成时显示掩护标志。

## What-if
1. 在演练或某轮真实回放的任意时刻暂停。
2. 拖动任一进攻或防守球员，可连续调整多人。
3. 播放或单步推演，观察队友接应、防守补位及传球空间变化。
4. 点击“撤销”回到编辑前；“返回原片段”清除这条假设并返回分叉时刻。

场上会明确标出“假设推演”。原教学演练和真实回放文件不被改写。选中球员后可固定/释放站位；进攻球员还可设为持球者或成为传球目标。“设为持球者”是编辑假设，不代表已经完成一次传球。空中球也能暂停拖动，其进度会保留。

如果在成功或失误之后编辑，假设会从当前站位重新组织进攻；失误后的球权恢复给出球者（没有出球记录时给代入角色），界面会明确提示。仍在飞行的传球保留进度。回退到已有假设的中间再编辑，只改从这一刻开始的过程，之前的运动保持原样。

假设推演采用本地规则，根据当前站位、球权与防守策略更新反应；它提供教学上的可能过程，不预测实战命中率。单条假设最多推演 3 分钟，可返回原片段重新探索。

## 正常 3D 练习
点击“开始 3D 练习”，从当前选择的战术预设开局。2D 的任意编辑分支不会带入 3D。

| 操作 | 按键 |
|---|---|
| 移动 / 加速 | WASD / 按住 Shift |
| 看向队友 | 鼠标；点击画面锁定鼠标 |
| 选择传球对象 | 指向队友出现目标提示；也可用 1–5 选择对应编号 |
| 直接传球 | 持球时按一下 Q，无需蓄力 |
| 要球 | 无球时按 E，队友会根据传球条件回应 |
| 实时俯视 | 按住 Tab，松开回第一人称 |
| 再 call 当前战术 | C，在当前局面重新组织；丢球后恢复进攻方持球 |
| 从预设重开 | R，已有练习片段会归档 |
| 结束并看回放 | V |
| 暂停回战术板 | Esc，可点击“继续暂停的练习”返回 |

传球速度、力度和接球辅助由系统处理。传球仍受实际线路影响，明显被防守封住的线路可能丢球；成功目标着重于站位和战术选择。角色头部有正面眼睛，朝向与当前行动一致。

单轮练习最长 5 分钟，届时自动结束并打开回放。失误或成功后都能按 C 再组织，也能按 V 查看这一轮。

## 记录与旧版本
程序会保留最近的实际练习列表，重新启动可继续读取。保存失败时会明确提示并提供重试。未知或损坏记录会跳过并说明数量。

旧的 Windows_Learning、Windows_LearningPolish、Windows_Readability 等程序及其 Replays 文件保持原样。五人制使用新记录格式，旧 3v3 回放继续在旧程序中查看。

本版包含正常第一人称桌面练习；未接入头显控制器或 3D What-if，也没有完整比赛计分、篮板与犯规裁判。
