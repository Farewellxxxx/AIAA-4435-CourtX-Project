# CourtX 5v5 使用说明

## 启动
打开 `Windows_FivePlayer_1117/CourtX.exe`（11 月 17 日版）。移动或分享时保留整个文件夹，单机离线运行，无需 Unity 编辑器。

## 两个入口
- **战术板**：左侧选择进攻战术和整体防守策略。展开“练习设置”可设置“你控制谁”和“开局谁持球”；收起后仍显示当前人物与开局持球人。
- **即时回放**：查看每一轮正常 3D 练习的实际经过。新记录保存在程序旁 `Replays5v5`。

角色是你代入的进攻球员，球权转移不会改变这个身份。五名进攻编号 01–05，五名防守编号 X1–X5。当前版本的防守基础是 2–3 联防，三种策略分别偏向均衡轮转、收缩护筐、外线施压。

## 共用的战术板操作
播放/暂停、倍速、时间轴和前后节点均在球场下方。点击时间轴上方的菱形标记可跳至一个战术阶段或事件；“更多”里有起点、单步和选人后的额外操作。右侧显示当前阶段、进攻目标和防守反应。短暂悬停球员可在球场内查看他的当前职责。

常规演练和回放只显示球员最近 2.5 秒的轨迹，越旧越淡、越细。进入暂停布防后，亮圈标出刚刚自动补位的防守人，约 1.5 秒后消失；这个画面不显示原回放的拖尾。球在空中时有传球参考线，掩护形成时有掩护标志。

## 暂停帧内布防
1. 在演练或某轮真实回放的任意时刻暂停。
2. 拖动任一进攻或防守球员，可连续调整多人。
3. 拖动时，其他防守人立即重新分配职责和位置；时间、战术阶段不前进，其他进攻球员不自动跑位。
4. 点击“撤销”回到上一次摆位；“恢复原站位”清除摆位，回到原来的这一帧；“恢复并播放”从原记录继续。

场上会标出“暂停布防”。你拖动的人自动固定在新位置，继续拖其他人时，之前摆好的人也保持不动。选中已固定的防守人后可以点“允许自动补防”。防守根据持球压迫、护筐、邻近接应点等职责分配，优先保护球侧和篮下。固定过多人可能留下弱侧空缺，悬停防守人可查看调整后的职责。

原教学演练和真实回放不被改写。成功、失误或传球飞行中的帧也可以摆位，原阶段和空中球进度保留；它不会偷偷重新开始一轮。选中进攻球员后仍可手动“设为持球者”，这是你明确改变球权的假设。

暂停布防时，“更多”里的“原片段单步”也会恢复原记录再前进；操作时间轴或前后节点同样回到原记录。这组工具用于推敲同一帧的站位，布防由教学规则计算。

## 选择历史练习

左侧按今天、昨天和更早的日期分组。卡片先显示战术、你操控的球员编号和该回合的队伍协作结果（协作达成、协作中断或练习结束），下面显示开始时间和时长。旧记录只保存到分钟的，仍按时分显示。绿色卡片标出当前选择；可滚轮浏览，或点选后用上下方向键切换。离开再返回即时回放时，仍打开上次选中的回合。

本机新版已复制 11 月 16 日版的 10 份历史回放。新练习保存到新版目录里的 `Replays5v5`。分享 ZIP 不包含个人练习记录；需要迁移时可自行复制这个文件夹。

## 正常 3D 练习
点击“开始 3D 练习”，从当前选择的战术预设开局。2D 的任意编辑分支不会带入 3D。

| 操作 | 按键 |
|---|---|
| 移动 / 加速 | WASD / 按住 Shift |
| 看向队友 | 鼠标；点击画面锁定鼠标 |
| 选择传球对象 | 指向队友出现目标提示；也可用 1–5 选择对应编号 |
| 直接传球 | 持球时按一下 Q，无需蓄力 |
| 要球 | 无球时按 E，队友会根据传球条件回应 |
| 实时俯视 | 按住 Tab，松开回第一人称 |
| 再 call 当前战术 | C，在当前局面重新组织；丢球后恢复进攻方持球 |
| 从预设重开 | R，已有练习片段会归档 |
| 结束并看回放 | V |
| 暂停回战术板 | Esc，可点击“继续暂停的练习”返回 |

传球速度、力度和接球辅助由系统处理。传球仍受实际线路影响，明显被防守封住的线路可能丢球；成功目标着重于站位和战术选择。角色头部有正面眼睛，朝向与当前行动一致。

单轮练习最长 5 分钟，届时自动结束并打开回放。失误或成功后都能按 C 再组织，也能按 V 查看这一轮。

## 记录与旧版本
程序会读取目录里所有有效的实际练习记录。保存失败时会提示并提供重试。无法读取的记录会跳过并显示数量。

旧的 Windows_Learning、Windows_LearningPolish、Windows_Readability 等程序及其 Replays 文件保持原样。五人制使用新记录格式，旧 3v3 回放继续在旧程序中查看。

本版包含正常第一人称桌面练习；未接入头显控制器或 3D What-if，也没有完整比赛计分、篮板与犯规裁判。
