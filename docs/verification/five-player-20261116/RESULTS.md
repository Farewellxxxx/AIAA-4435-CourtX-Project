# 11 月 16 日暂停布防修正版

## 修改

- **暂停单帧布防**：拖动任意攻防球员，立即根据职责重排其他防守人；不需要播放或确认。固定你拖动的人，保持其他进攻位置、时间、阶段及空中球进度。支持多人摆位、撤销、恢复。成功/失误帧也不重开战术。播放按钮明确标为“播放原片段”，回到原记录。
- **历史回放**：按记录 ID 保存当前选择；列表绿色高亮、球场轮次、底部日期/时长共同表明当前回合。切换入口后保留所选历史。点击坐标、滚动偏移和卡片间隙采用统一计算；列表支持上下键。新回合时间精确到秒。
- **线条**：球场线适度加粗，采用距离覆盖与抗锯齿纹理，圆弧连续；拖尾采用相同的平滑覆盖，避免分段接缝叠亮，保留 2.5 秒渐细渐隐。

参考用户提供的 CourtLab_WhatIf.html 的职责优先级、固定位置邻近覆盖及最小代价分配思想。规则适配 2–3 联防，没有移植 Box-and-1 的专盯者。正常 3D 规则与操作保留。
