# CourtX 战术学习与复盘中心

启动 `Windows_Learning/CourtX Learning.exe`。本版本是单机离线的 Unity 3v3 半场学习原型，包含两套配合：高位挡拆，以及高位接应与传切。旧版本程序仍在原来的独立目录中。

## 第一次体验：约五分钟

1. 在“战术演练”选择高位挡拆、01 持球、Drop 沉退。播放或慢放，使用前后节点观察 04 掩护、01 使用掩护以及 05 弱侧接应。右侧说明可以滚动。
2. 点击“从开局进入练习”。WASD 移动，Shift 跑，按住 Tab 查看实时俯视，松开回到第一人称。球场不会因为 Tab 暂停。
3. 持球时用 1 / 2 选择队友，按住 Q 准备、松开传球；无球时用 E 要球。先形成距离和角度，队友才有条件传球。传球可以被干扰、偏转或截断。
4. 按 V 结束并保存本段练习。复盘中，拖动时间轴或播放，查看六个人、篮球和对应传球分析。按 R 可重试；Esc 返回学习中心。
5. 在复盘右侧把该轮设为 A，进入 What-if，点击“恢复 A 的开局”，改成 Switch 换防，再练一次并按 V。两轮初始状态相符时，B 会自动加入对比。

## 四个页面

| 页面 | 操作与含义 |
|---|---|
| 战术演练 | 两套配合、01 / 04 两个角色；挡拆有沉退、换防、夹击。展示自己项目中录制的教学示例，并可进入匹配配置的实际练习。 |
| What-if 对比 | 先在真实复盘设定 A，再用相同开局练 B。检查战术、角色、种子、初始六人站位、球与球权。可改变防守和自己的操作。 |
| 读防守挑战 | 六道题，每题三个选择；错误选择也有具体解释。题目固定在对应时刻；作答后可进入对应演练观看经过，或从该场景开局亲自练习。 |
| 实战复盘 | 读取程序旁 Replays 中最近的实际练习。篮球、六人轨迹、出手目标和本地分析随时间轴同步；可查看旧轮、设为 A、重新练习。 |

六道挑战覆盖：使用掩护、读换防、夹击后的短出口、无球接应角度、传后空切，以及回传受阻时的弱侧转移。

## 看懂图

- 青色为进攻，橙色为防守；号码为 01、04、05、11、12、13。白色外圈是你控制的角色，金色外圈是持球人。
- 金色篮球表示记录中的球位置。重叠时会稍微错开并用细线指回原位置，避免被号码盖住。
- 实线是最近两秒的运动轨迹；金色虚线箭头是一次已发生传球的出手目标。目标和实际球路是两回事。
- 播放时位置按采样插值；通常约 0.2 秒一个采样，出手有额外记录。动画展示不等于逐帧物理重算。

## 对比与复盘的边界

教学示例始终标明“教学示例”，使用录制的 4435 开局，不计入你的练习历史。What-if 使用实际练习结果，不自动编造另一种选择的结果，也不支持任意中途存档恢复。切换 A / B 保留当前回放秒数；较短记录停在最后一帧。

“开放线路”按出手时的规则判断，与最终是否接稳分开统计。“尚未落定”表示结束记录时球仍在传递，不能当成失误。两轮人的操作可能不同，因此差异不能全部归因于防守方式。

这是配合与决策训练原型：目前的“配合完成”表示形成规则定义的空间或传接球优势，不是投篮得分。没有完整比赛、篮板、犯规裁判或五人制战术。没有视线记录，因此复盘只描述行动和事件，不推断你的注意力或心理意图。

## 暂停、保存和稳定版

Esc 返回学习中心会暂停实战；“继续暂停的练习”恢复同一未结束回合。按 V 后该回合已结束，再练会生成新记录。切换战术启动新练习时，已有的有效片段也会归档。

实际练习存为程序旁 `Replays/*.json` 和同名文本报告；界面显示最近 30 条，启动时检查文件有效性。旧记录若缺少可还原配置，可以观看，但不会凭空猜测配置重开。可选 LLM 解说接口保留，默认完全使用本地规则，不发送网络请求。

本次独立程序位于 `Windows_Learning`；`Windows`、`Windows_Tactics`、`Windows_Reactive`、`Windows_Recap` 保留旧程序。代码在 `feature/tactical-learning-hub`，升级前稳定源代码标记为 `v0.4-recap-stable-20261111`。
