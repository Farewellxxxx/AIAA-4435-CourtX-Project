# 学习中心界面修整

2026-11-11。根据试玩反馈，集中修整字体、格式、线段清晰度和页面操作。入口为 `Windows_LearningPolish/CourtX Learning.exe`；原 `Windows_Learning` 程序和其中两段用户练习原样保留。

## 看得见的变化

| 原问题 | 本轮调整 |
|---|---|
| 文字随整个界面缩放，缩小时模糊 | 文本按实际屏幕像素和整数字号绘制，设定最小字号；统一标题、正文和辅助说明层级。 |
| 球场圆弧、球员外圈有锯齿和短线接头 | 球场按当前分辨率缓存抗锯齿线条，圆环使用连续覆盖率绘制；保留原场地尺寸、运动轨迹和球路含义。 |
| 六人说明挤在一段中 | 按球衣号码分卡片展示，自己操控的角色排在前面，卡片高度随文字变化。 |
| 小窗口出现截字、题目名称不自然换行 | 缩短导航名称和固定提示，为图例及底部键位提示补足行高；历史记录卡片按实际文本高度排列。 |
| 时间轴不醒目，题目页的播放按钮像失效 | 提高时间轴和选中状态对比度；题目页直接说明定格时刻，以及如何观看对应演练。 |
| 操作说明让人误以为复盘页支持 R 重试 | 明确 R 用于实战重开；复盘点击“同一开局再练”。 |

四个页面、现有 3v3 配合、球权/防守规则、真实记录格式与 LLM 接口保持兼容。本轮不增加战术和游戏机制。

## 检查与迭代

1. 第一轮：在真实窗口复现小字体和细线问题，调整像素绘制、卡片和控件。四种窗口各截取五种状态，共 20 张运行截图；没有运行异常。截图进一步暴露了短线圆弧接头和小窗口提示裁切。
2. 第二轮：改为缓存连续球场线条和圆环，精简左侧文案并加高题目提示。再次检查 20 张截图。独立只读审核未发现严重或功能性缺陷，指出最小窗口下底部两行仍略有裁切。
3. 最终修整：补足图例/键位行高；实际打开用户历史时发现卡片第三行空间偏紧，一并改为按内容测量。最终截图和发布包校验保存在下列证据目录。

检查尺寸为 1024×576、1280×720、1920×1080 和 1280×800；状态覆盖演练、未作答题目、答题反馈、历史复盘、A/B 对比。20 张 QA 截图中的回合是渲染夹具，不是用户练习或学习效果证据。低于 1024×576 的窗口尚未验收；Windows 捕获工具会将物理截图缩小为逻辑像素，查看线条细节应优先使用原尺寸 QA PNG。

已有自动化检查共 138 项通过：教学目录/记录规则 79，学习与实战生命周期 27，复盘规则 22，复盘场景 10。最后两项布局修整后重复运行生命周期检查。可视修整通过实际渲染前后比较验收，没有增加只重复样式实现的单元测试。

实际程序以 1280×800 启动，使用鼠标验证时间轴拖动、右侧滚动条、页签、答题及自动定位反馈、两段原始练习选择；点击主按钮进入第一人称练习，再按 V 保存并返回复盘。鼠标滚轮工具输入的结果未能稳定确认，因此不把滚轮计作本次已通过的原生输入项。人工验收生成的回合独立存入 `native-records`，未作为用户默认历史交付。
