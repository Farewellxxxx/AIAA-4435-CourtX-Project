## 执行裁决

- 在用户要求的新分支内复用现有 Unity checkout，稳定源码打标签和归档、程序独立输出；这样不重复导入大型 Library。代价是以后切换源码分支前应先关闭 Unity。
- 执行文件整理的是已经获批准的 prompt，不再增加确认轮；工程记录和原始测试保留，满足用户保存结果的要求。
- Windows 下使用 PowerShell 管理运行和证据，Git Bash 仅用于技能的审查包辅助脚本。
- 保留旧版暂停语义：Esc 冻结要球剩余时间，继续时恢复；重开／换角色才清除请求。计划 Review Focus 中概括为所有情况下都“清除”过宽，按已批准的“保留原控制行为”裁决。代价是暂停后仍可能执行未过期的要球，这与原版一致。
- 开源只移植 BasketWorld 的小段压力计算；未引入 UnityHFSM、NeuralCourt 或 RL 堆栈。战术规则仍是本项目实现，并非外部训练好的篮球策略。

## 范围

这是 3v3 配合练习原型，没有投篮计分、篮板或完整比赛。防守、传球建议和备选方案是局部启发式；未声称教练评分或学习效果已验证。球不会因为“建议成功”而自动归属接球人，身体碰撞、接球位置和反应仍会改变实际结果。
