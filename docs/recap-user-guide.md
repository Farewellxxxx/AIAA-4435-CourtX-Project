# CourtX 回合复盘版

运行 `Windows_Recap/CourtX Recap.exe`。原有 `Windows_Reactive`、`Windows_Tactics` 和自由练习版保持不变。

练习操作保持原样：WASD 移动、Shift 跑、按住 Tab 看实时俯视、1/2 选接球人、按住并松开 Q 传球、E 要球、V 打开回合复盘。

## 看懂复盘

- 左侧是同一场地的半场图，包含篮筐、篮板、三分线、禁区、罚球圈和中圈半圆。
- 青色编号是进攻球员，橙色是防守球员；白圈是你，金色外圈是当时的持球人。
- 带球缝的金色篮球是球的位置。如果和球衣编号重叠，图标会稍微让开，并用细连接线指向记录位置。
- 浅色细线显示六名球员近 2 秒的移动；金色实线显示篮球近 2 秒的轨迹。
- 金色虚线箭头表示所选传球的出手目标，不代表球一定沿该线飞到接球人手里。

## 播放与评语

打开时暂停在默认选中的出手位置。点击“回到开头”，再点击“播放”，可以从开始看整段配合。“暂停”停在当前时刻；点击“1× 正常”切换“0.5× 慢放”。拖动时间轴会暂停并定位。

“上一出手 / 下一出手”会同时切换画面和右侧评语。播放经过另一位球员的出手时也会自动切换。第一球出手前不显示后面的传球判断。

右侧区分出手时预测风险和该次传球最终结果；“出手前防守”只引用当时已经发生的变化。较长评语可以在右侧滚动到底。可选 LLM 解说接口保留且默认未配置；未来接入后，整段解说会明确标注“不随出手切换”。

记录约每 0.2 秒采样，并额外保存出手瞬间；播放器对位置作插值。这是记录回放，不是逐帧物理重演，也不会改变已结束练习或驱动场上的角色。记录触及上限时，以实际存下来的片段为准。

每段 JSON 和默认本地评语 TXT 保存到程序旁的 `Replays` 文件夹。当前版本在练习结束后查看本次回合，尚未增加历史文件选择器。
